# Proyecto de juego multijugador en Unity 6.

Proyecto desarrollado en Unity 6 para dispositivos móviles Android.  
Multijugador en tiempo real y registro de estadísticas en base de datos.

---

### 🛠️ Tecnologías y servicios usados

- **Unity 6** — motor principal para el desarrollo del juego.  
- **Netcode for GameObjects (NGO)** — para la sincronización multijugador en tiempo real.  
- **Firebase** — autenticación de usuarios y base de datos para guardar estadísticas.  
- **Relay** — para facilitar la conexión de los jugadores en partidas online.  
- **Lobby** — gestión de salas y emparejamientos para el multijugador.
